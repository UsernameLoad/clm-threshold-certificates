# Certified threshold bounds for the dissipative Constantin-Lax-Majda family

Certificate records and code for three papers.

1. *Certified two-sided bounds for the blowup/decay threshold of the dissipative
   Constantin-Lax-Majda equation across the fractional-dissipation family.*
2. *An exact blowup time for the a = 1/2 generalized Constantin-Lax-Majda equation from
   single-mode initial data.*
3. *The sigma-dial at the Hou-Luo corner: a bench note on the 2D Boussinesq equations with
   fractional thermal diffusion between walls.*

Sources and PDFs are in `papers/`.

## What is here

The first paper proves computer-assisted two-sided bounds on the blowup/decay threshold of a
one-dimensional model equation across a family of fractional dissipation orders. The 54 files in
`certificates/` are those theorems: each is a machine-checked enclosure record, and each can be
verified in two lines without rerunning anything. Run `python code/verify_certificates.py` to check
all of them.

`VERIFICATION.md` explains the check, and lists the claims that were withdrawn during the work.

**No claim is made about the three-dimensional Navier-Stokes equations.** The mathematics here
concerns model equations and a two-dimensional numerical bench.

| Folder | Contents |
|---|---|
| `certificates/` | 54 certificate records (`.npz`): 41 decay, 11 ladder, 2 earlier sigma = 2 blowup |
| `code/` | The solvers, instruments and analysis scripts behind the published results, the table and figure generators, and the certificate verifier |
| `records/` | Measurement outputs quoted in the papers |
| `papers/` | LaTeX sources, PDFs and the figure |

## Not included

Published papers by other authors are cited, not redistributed. The raw field archives from the
two-dimensional runs (about 1 GB) are too large to host and are available on request.

## Running the code

Python 3.13 with NumPy, SciPy and mpmath; the certified interval paths additionally use python-flint
(Arb). Scripts are stage-based and deterministic: run them as `python <script> <stage>`. Reruns are
bit-identical by design.
